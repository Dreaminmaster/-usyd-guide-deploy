# USYD Radar — public event data branch

This branch stores public event metadata only. It is separate from the USYD Bible website, which runs from `main`.

- `latest.json`: last successful unified feed snapshot, updated by GitHub Actions.
- `snapshots/YYYY-MM-DD.json`: daily historical public event snapshots.
- `curated.json`: official-source events additionally verified and contributed via ChatGPT GitHub connector; **not** a personal data store.
- `status.json`: job health and source status (optional).

Events and news are not official safety alerts. Eligibility and cancellations must always be verified with the original organiser.

No private student emails, Canvas records, identity, passwords or API keys belong here.
